# Module 5 — IV Flow Rate Calculations

Intravenous (IV) therapy delivers fluids, electrolytes, and
medications directly into the bloodstream. This module applies
unit cancellation to IV calculations — programming pump rates,
calculating how long a bag will run, counting gravity drip rates,
and verifying continuous medication infusions.

This module builds directly on unit cancellation from Module 2
and the dosage calculation skills from Module 4.

---

## What You'll Learn

By the end of this module you should be able to:

- Calculate IV flow rates in mL/hr for pump programming
- Calculate infusion time for a given volume and rate
- Calculate drip rates in drops per minute (gtt/min)
  for gravity infusions
- Calculate flow rates for continuous IV medication infusions
- Verify doses from running infusion rates
- Identify and respond to unreasonable pump settings

## Clinical Relevance

!!! danger "IV Errors Are Especially Dangerous"
    Unlike oral medications, which are absorbed gradually,
    IV medications enter the bloodstream instantly.
    There is no opportunity to reverse an error once
    an infusion has begun.

    Always verify your calculation **and** the pump settings
    independently before starting an infusion.

!!! info "Equipment You Will Use"
    | Equipment | Purpose |
    |---|---|
    | IV infusion pump | Precise rate control in mL/hr |
    | Macrodrip set (10–20 gtt/mL) | Standard gravity infusions |
    | Microdrip set (60 gtt/mL) | Precise low-volume infusions |
    | Burette | Pediatric and critical care dosing |

!!! tip "Before You Begin"
    Make sure you are comfortable with unit cancellation
    from Module 2. Every calculation in this module is a
    unit cancellation chain — time, volume, concentration,
    and rate all need to cancel correctly.

    If any setup feels unclear, return to
    [Unit Cancellation](../module2/unit-cancellation.md)
    before continuing.
